# Amaterasu

Roy App Worksによる、独自コンピューティング基盤の長期研究プロジェクトです。

## 現在の状態

**Planning / Research Preparation**。企画・研究準備段階です。この雛形は未公開であり、OSや演算エンジンの実装・性能改善実証を報告するものではありません。

## 研究目的

既存技術との互換性を重視しながら、独自OS・演算方式・グラフィック技術を段階的に研究します。国内で設計・開発・運用できる独立性の高い基盤を長期的に目指します。既存の国外製機器や技術に依存する段階を完全自立とは扱いません。

初期対象はグラフィック処理に特化したゲーム用実験ウィンドウ環境です。macOS上の実験アプリケーションと仮想環境の独自カーネルを区別して並行研究します。Windows対応、既存ゲーム互換、独自言語・専用ハードウェアの実装は初期必須ではありません。

## 研究領域

OS（Operating Systems）、計算機構成（Computing Architecture）、グラフィック処理（Graphics Processing）、変数・演算方式（Variable Arithmetic）、言語（Programming Language Research）、通信基盤（Network Architecture）。
