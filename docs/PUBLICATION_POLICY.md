# 公開方針

[概要](../README.md) / [研究方針](RESEARCH_POLICY.md)

本雛形は公開候補です。生成・静的検査だけで公開承認を得たものとは扱いません。GitHub公開とWeb公開は別々の承認対象です。

| 分類 | 取扱い |
|---|---|
| 研究概要・開発履歴・技術的背景・実験結果の概要 | 公開候補。内容確認後に個別承認 |
| 未公開アルゴリズム詳細 | 原則非公開 |
| 秘密鍵・認証情報 | 公開禁止 |
| 未公開製品設計・商用化前の重要技術 | 公開前審査とユーザー確認 |
| 特許出願を検討する可能性のある技術 | 公開前に別途確認 |
| 大容量実験データ | 原則ローカル保管 |

公開可否は自動判定しません。秘密情報検査は補助であり、人による公開内容の確認が必要です。内部監査報告、ローカル絶対パス、個人情報、運用情報を公開候補へ混入させません。未公開の相互リンクは有効化しません。

研究記録は対象日・作成日・更新日を区別します。実施していない実験は未実施とし、結果を捏造しません。新規性や他社技術との関係を根拠なく断定しません。引用時は資料と既存技術の範囲を記録します。

GitHubにはMarkdown中心の軽量記録を置きます。動画、ビルド成果物、仮想ディスク、大容量ログ・実験データ一式を自動送信しません。.gitignoreは補助であり、公開対象を個別に確認します。本リポジトリは研究開発履歴の公開を目的とし、現時点ではオープンソースライセンスを設定せず、第三者への包括的な再利用許諾は行いません。GitHub利用規約に基づく閲覧・フォーク等は別に扱います。LICENSEファイルは設置しません。名称利用は公開前の検討事項です。

## 将来の自作サーバー移行

静的HTML・CSS、UTF-8 Markdown、相対リンク、安定した記録IDを基本とし、データベース・外部API・GitHub固定URLへの内部依存を避けます。将来の移行候補は研究履歴、技術資料、実験資料、審査済み画像・動画・公開データです。形式・記録ID・相対構造を維持し、URL変更時にはリンクを点検します。今回サーバー構築やDNS・ネットワーク・ファイアウォール設定変更は行いません。
