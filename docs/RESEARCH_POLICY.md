# 研究方針

[概要](../README.md) / [公開方針](PUBLICATION_POLICY.md) / [記録テンプレート](DEVELOPMENT_RECORD_TEMPLATE.md)

既存技術・研究仮説・決定済み方針・将来構想を区別します。独自方式の速度、安全性、省電力性を事前に断定せず、有効性が示されなければ既存方式を維持します。

初期対象はゲーム用グラフィック処理です。ホスト実験アプリケーションと独自カーネルを技術的に区別し、OSと演算方式を並行研究します。独自演算の変更がOS重要機能を破壊しない境界を設計します。

比較では入力・描画内容・解像度・ハードウェア・品質条件を揃え、変換・復元・同期を含む費用と演算部を分けます。正確性を先に確認し、CPU・GPU・メモリ帯域の制約、仮想環境と実機の差を区別します。電力は測定できる場合だけ扱い、未測定をゼロとしません。

研究開始から設計変更、実験、失敗、改善を記録します。既存技術を参照した場合は技術名・資料・参照範囲を残します。独自性を強調する断定より、再現可能な事実を優先します。

将来はGit履歴、署名付きコミット、タグ、ハッシュを証跡の補助に利用できます。これらは法的な先行権や非侵害を保証しません。今回の雛形ではGit初期化・コミットは行いません。
